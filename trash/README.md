# trash

기능 아이디어를 빠르게 확인하려고 만든 실험용 파일을 모아 둡니다.
서비스 코드(`app/`, `server/`)에서 가져다 쓰지 않으며, 빌드·배포·E2E에 포함되지 않습니다.

## 파일

- `locate-element.js`: 웹 화면 캡처 이미지와 질문을 AI Gateway로 보내, 질문이 가리키는 UI 요소의 위치(중심 좌표·영역)와 생김새 설명을 JSON으로 받아 봅니다. 호출에 쓴 토큰 수와 대략적인 비용도 함께 출력합니다.
  - 실행할 때 이미지 경로와 질문을 인자로 넘기며, 넘기지 않으면 `image.png`와 기본 질문을 씁니다.
  - 실행하는 폴더의 `.env`에서 `AI_GATEWAY_API_KEY`를 읽습니다. 키는 커밋하지 않습니다.
  - PNG 이미지만 받고, 좌표는 원본 이미지 픽셀 기준입니다(API 컨벤션의 0~1 비율 좌표와 다름).
- `tab-share-spike/`: 탭 공유·iframe 캡처·음성 기능이 키트 E2E(Playwright)에서 동작하는지 확인한 실험과 일지입니다. 결과와 결론은 그 폴더의 README에 있습니다.

## 보류한 아이디어

- 이미지 + 음성으로 묻기: 질문 텍스트 대신 녹음 파일을 같이 보내는 방식. Claude는 음성 입력을 받지 않아 Gemini 계열 모델로 바꿔야 합니다.
- 화면 따라가기: 매 프레임 AI를 부르지 않고, 화면이 크게 바뀔 때만 AI를 호출하고 그 사이에는 템플릿 매칭으로 위치만 다시 찾는 방식.
